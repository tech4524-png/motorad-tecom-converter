# MotoGateway (Motorad Invoice Converter)

ממיר קבצי חשבונית מפריוריטי (XLS/טקסט מופרד-Tab) לפורמט TXML 2.5 של TECOM, רץ כשירות Windows עם ממשק ניהול מבוסס דפדפן. שם המערכת בממשק: **MotoGateway**. הממשק תומך בעברית ואנגלית (מתחלף במסך הכניסה או דרך `/set-language/<he|en>`), עם לוגו מוטוראד האמיתי במסך הכניסה ובסרגל הניווט.

## מבנה הפרויקט

```
app/
  config.py         - ניהול הגדרות (JSON), הצפנת סיסמה
  db.py             - לוג SQLite של המרות
  xls_reader.py     - קריאת קובץ הקלט (Tab-delimited) וקיבוץ לפי חשבונית
  payment_terms.py  - פענוח שדה תנאי התשלום (טקסט חופשי -> שדות מסודרים)
  tecom_xml.py      - בניית ה-XML לפי תקן TECOM TXML 2.5 (הליבה העסקית)
  engine.py         - אורכיסטרציה: קלט -> המרה -> פלט/ארכיון/שגיאות + לוג
  watcher.py        - ניטור תיקיות (watchdog) + סריקה תקופתית כגיבוי
  webapp.py         - Flask: התחברות, הגדרות, פרופילים, לוג, עדכונים
  updates.py        - החלת חבילות עדכון בלי התקנה מחדש
  country_codes.json - טבלת מיפוי שם מדינה -> קוד ISO (כ-440 ערכים)
  templates/, static/ - ממשק המשתמש (HTML/CSS, בעברית, RTL)

service_windows.py  - עטיפת Windows Service (pywin32) - נקודת הכניסה ל-EXE
run_dev.py           - הרצה מקומית לבדיקות (ללא שירות Windows)
build/
  pyinstaller.spec   - בניית ה-EXE
  installer.iss      - בניית מתקין Windows (Inno Setup)
  make_update_package.py - בניית קובצי עדכון עתידיים
tests/
  sample_files/      - שני קבצי הדוגמה האמיתיים שהתקבלו מהלקוח
  test_conversion.py - הרצת מנוע ההמרה מול קבצי הדוגמה, ללא צורך בשרת/דפדפן
```

## הרצה לבדיקה מקומית (לא בפרודקשן)

```
pip install -r requirements.txt
python3 run_dev.py --port 8080
```
ואז גלישה ל- http://localhost:8080 (משתמש admin, סיסמה כפי שהוגדרה מראש - ראו app/config.py).

## בדיקת מנוע ההמרה בלבד (הכי מהיר, בלי שרת)

```
python3 tests/test_conversion.py
```
מריץ את שני קבצי הדוגמה האמיתיים ומדפיס את ה-XML שנוצר.

## בניית קובץ ה-EXE להתקנה על שרת ייצור

ראו `BUILD_INSTRUCTIONS.md` - **חובה לבצע על מחשב Windows**, לא ניתן מסביבת הפיתוח (Linux).

## החלטות עסקיות מרכזיות שהוטמעו (לפי מה שסוכם עם הלקוח)

- קובץ קלט = חשבונית אחת תמיד (ללא פיצול לכמה חשבוניות).
- הכותרת משתמשת ב-OrderRef (לא DesAdvRef) - החשבונית מופקת ישירות מול הזמנת הלקוח.
- PartyNumber של מוטוראד משתנה לפי הזמנה ומגיע מהקובץ (עמודת SELLER_PARTY), לא קבוע בהגדרות.
- אחוז המע"מ (ALLINVOICETAX) הוא ערך יחיד לכל החשבונית, משוכפל אוטומטית לכל השורות ולסיכום.
- הנחת שורה (DISCOUNT) היא תמיד אחוז, לא סכום.
- קוד המוצר (PRODNUMBER) נשלח כפי שהוא, כולל קידומת.
- שמות מדינה מלאים מומרים אוטומטית לקוד ISO (טבלה מובנית + מיפויים מותאמים מהממשק).
- תנאי תשלום בטקסט חופשי מפוענחים לשדות מסודרים; פענוח שנכשל -> הקובץ מועבר ל-errors, לא מנחש.
- כל השדות בסעיף ה"קבועים" (פרטי מוטוראד, בנק, MessageFunction וכו') ניתנים לעריכה מהממשק, לא קשיחים בקוד.

לרשימת השדות המלאה ולנימוקים המפורטים, ראו את המסמך `TECOM_XLS_Fields_Spec.md` שהועבר בשיחת התכנון.
